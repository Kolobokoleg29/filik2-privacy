# Два сайта из одного GitHub-репозитория

Этот публичный репозиторий `Kolobokoleg29/filik2-privacy` обслуживает две независимые публикации.

## 1. GitHub Pages — действующая политика конфиденциальности

- Адрес: https://kolobokoleg29.github.io/filik2-privacy/
- Файл: `/index.html` (корень репозитория)
- Источник GitHub Pages: ветка `main`, папка `/(root)`
- Не изменять адрес политики конфиденциальности в RuStore и не переключать Pages на `developer-site`.

## 2. Cloudflare Pages — сайт разработчика для проверки приложения в РСЯ

Источник сайта внутри *того же* репозитория: каталог `developer-site/`.

1. Открыть https://dash.cloudflare.com/ → **Workers & Pages**.
2. Создать **Pages** проект с вариантом **Connect to Git** (GitHub). При необходимости авторизовать доступ Cloudflare к репозиторию `Kolobokoleg29/filik2-privacy`.
3. Выбрать репозиторий `Kolobokoleg29/filik2-privacy`, production branch `main`.
4. Конфигурация сборки:
   - Framework preset: **None**.
   - Build command: **пусто** (обычный HTML).
   - Root directory: корень репозитория (`/` или поле не задавать).
   - Build output directory: **`developer-site`**.
5. Создать и дождаться успешной публикации. Cloudflare выдаст конкретный адрес `https://<имя-проекта>.pages.dev/`. Не предполагать адрес до фактического деплоя.
6. Проверить в браузере оба адреса:
   - `https://<имя-проекта>.pages.dev/` — открывается сайт разработчика, упоминается Рябцев Олег, ссылка на FILIK2 в RuStore и контакты.
   - `https://<имя-проекта>.pages.dev/app-ads.txt` — **HTTP 200, text/plain, без HTML и редиректов**; первые строки совпадают с файлом `developer-site/app-ads.txt`.
7. В карточке **FILIK2** в RuStore указать адрес **сайта разработчика** (в публичном соответствующем поле или в описании, если отдельного поля нет), чтобы робот Яндекса смог обнаружить его.
8. В РСЯ для приложения ID `20226358` нажать **«Отправить на проверку»** после публикации адреса и обновления карточки RuStore. По сообщению поддержки проверка файла — не чаще раза в сутки. Проверка доступа не подтверждена, пока статус РСЯ не изменится.

### Обязательные предосторожности

- `developer-site/app-ads.txt` — **точная копия полученного в кабинете РСЯ файла**, включая DIRECT и RESELLER строки. Это публичные идентификаторы рекламных продавцов, не пароли.
- Адрес `https://kolobokoleg29.github.io/filik2-privacy/developer-site/app-ads.txt` может быть доступен через GitHub Pages, но **не является корневым адресом файла для проверки**, поэтому для РСЯ использовать **корень домена Cloudflare**.
- До проверки не утверждать, что произвольный субдомен `.pages.dev` гарантированно принимается РСЯ. Если Яндекс не сможет определить домен, обратиться в поддержку и при необходимости использовать собственный домен.
- GitHub Pages по-прежнему использует `/index.html` из корня репозитория. Добавление папки `developer-site` не меняет действующую страницу.
- В действующей политике конфиденциальности пока описывается **myTarget** (согласно опубликованной сборке). Перед выпуском RuStore-обновления с Yandex Mobile Ads обновить политику и сведения о запрашиваемых данных, но **не менять их преждевременно**.

### Изменение app-ads.txt

Периодически скачивать актуальный файл из РСЯ → **Настройки → Общие → app-ads.txt**. Обновлять `developer-site/app-ads.txt` без потери строк других активных рекламных сетей; при изменении файла дождаться нового деплоя Cloudflare и проверить его URL.
